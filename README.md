
# 🌊 aquawatch

*(Formerly Jakarta Rain Alert)*

**aquawatch** is a real-time global weather monitoring and notification system designed to track heavy rainfall, rising water levels, and potential flood risks worldwide. Currently in active development, the project has expanded from its original Jakarta-only scope to provide vital weather alerts and infrastructure simulations on a global scale.

## 🌟 Key Features (Under Development)

* **Global Precipitation Tracking:** Integrates with worldwide meteorological APIs to monitor rainfall rates across different countries and regions.
* **Universal Alert Thresholds:** Adaptable warning systems that trigger notifications based on localized flood risk levels and weather severity.
* **Extensible Notifications:** Built to support automated webhooks for instant messaging platforms like Telegram, Discord, and WhatsApp.
* **Interactive Simulation:** Tools to visualize how extreme global weather impacts drainage and regional infrastructure.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18 or higher) or Python 3.10+ (depending on the implementation stack)
* Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ponskigila-hub/aquawatch.git
   cd aquawatch
   ```

2. Install dependencies:
   ```bash
   npm install
   # or pip install -r requirements.txt
   ```

3. Configure your environment variables (copy `.env.example` to `.env` and add your global weather API keys / webhook URLs).

4. Run the application:
   ```bash
   npm start
   # or python main.py
   ```
